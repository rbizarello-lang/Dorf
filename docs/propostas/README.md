# Propostas e pesquisas (registro)

Relatórios dos agentes que planejaram e executaram as rodadas de melhoria do Retalhos. Nada aqui é código do jogo: é material de leitura e decisão.

- `E1-proximas.md`: ideias de encaixe próximas do original (simulação em `E1-simulacao.ts.txt`).
- `E2-radicais.md`: ideias de encaixe completamente diferentes.
- `E3-relevo-peca.md` (na branch `dorf/e3-relevo-peca`): relevo na própria peça.
- `cores.md` (na branch `dorf/c1-cores`): diagnóstico de cores e tons.
- `X1-colcha-rejeitada.md`: o modo Colcha, rejeitado pelo Roger.
- `temas/`: pesquisa dos 5 temas, do relevo e o plano da rodada 3.
- `aval/`: avaliação visual da rodada 2 (árvores, casas, campos, chão e luz).
- `plano-D1-D20.md`, `REFERENCIAS.md`, `BRIEF-agentes.md`: plano, referências visuais e roteiro comum dos agentes.
